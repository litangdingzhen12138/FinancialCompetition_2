# 新环境部署指南

在另一台电脑上从 Gitee 克隆本仓库并运行的标准步骤。

## 标准部署步骤

```powershell
# 1. 克隆仓库
git clone https://gitee.com/guocj12138/financial-competition_2.git
cd financial-competition_2

# 2. 安装依赖（二选一）
uv sync
# 或
python -m pip install -r requirements.txt

# 3. 配置环境变量
copy .env.example .env#直接把我给你的复制过去
# 然后编辑 .env，填入真实的 TEXT2SQL_LLM_API_KEY
```

`.env` 关键配置项：

```env
TEXT2SQL_LLM_URL=https://api.deepseek.com/chat/completions
TEXT2SQL_LLM_API_KEY=your-deepseek-api-key
TEXT2SQL_LLM_MODEL=deepseek-v4-flash
TEXT2SQL_LLM_TIMEOUT=20
TEXT2SQL_LLM_RETRIES=1
```

> `.env` 被 `.gitignore` 排除，不会进入仓库，必须在新环境手动创建。

## 构建数据库

构建数据库要首先保证有原始.xlsx数据集，直接把我给你的文件解压到项目中即可。

数据库会在首次执行任意命令时由仓库内的 `数据集.xlsx` 自动构建，无需手动操作：

```powershell
# 方式一：直接提问（首次会自动构建 DuckDB）
python -m text2sql.cli "把江苏省E市农商行2025年10月31日的不良率、拨备覆盖率、逾期率和资本充足率都列出来，并告诉我各自在全省排第几"

# 方式二：显式构建一次数据库
python -m text2sql.cli --build-db

# 方式三：JSON 输出
python -m text2sql.cli "2026年3月末，哪家农商行的不良贷款率最低？" --json
```
