## 二、最核心的问题:多轮上下文没有真正继承

这是当前多轮对话**最致命的缺陷**。从 `diagnostics` 的 `session_state` 可见:在紧接上一轮的追问里,`last_metrics`、`last_date`、`last_organizations` 几乎恒为空(`[]` / `null`),即上一轮明确的指标 / 机构 / 日期没有传递到下一轮。三类后果:

### 1. 指标继承失败 → 直接报错

紧跟上一轮的追问,系统不知"算哪个指标",LLM 给出 `metrics: []`、`current_date: null`,重试后报错。

| index | 问题(节选) | 上一轮已明确 | 失败原因 |
|---|---|---|---|
| 2 | "比二季度末变动了多少?" | C 市三季度净利润 | `last_metrics: []`,指标丢失 |
| 4 | "那四季度末呢?相比三季度…" | C 市净利润 | 同上 |
| 7 | "…较2024年末增长了多少?" | C 市净利润 | 同上 |
| 8 | "这个增量在全省排第几?" | C 市净利润增量 | 同上 |
| 10 | "回落了多少?净利润/存款比?" | C 市净利润/存款 | 指标+日期均丢,SQL 解析失败 |
| 25 | "K市同期变化情况呢?" | K 市不良率 | 同上 |

### 2. 日期继承失败 → 默认退回 2024-12-31 基准日(出现最多)

当上下文日期丢失时,系统退回"较年初基准日 2024-12-31",导致查询日期、数值、全省均值全部错位。

| index | 应查日期 | 应得值 | 实查(错误) | 实得值 |
|---|---|---|---|---|

| 50 | 2026-04-30 | L 市净利润 204.66 / 存款 88.17 | 2024-12-31 | 196.81 / 87.54 |

## 三、其他实质错误(与上下文无关的独立逻辑 bug)

### 1. 阈值判断逻辑反向(index 29)

- **问题**:"全省资本充足率低于 10.5% 的有几家?"
- **标准**:0 家(13 家全部 ≥ 10.5%)
- **结果**:把每家都标成"**不满足**"——把"≥10.5 才达标"误判成"<10.5 才达标",阈值比较方向反了。

### 2. 单位/口径错误(index 42)

- **问题**:L 市 2026-04 净利润对比全省均值(应 204.66 vs 164.19,差 40.47)
- **结果**:`result_value=2074.85`(疑似全省当期值求和)、`province_average_value=159.6`(用了 2024-12-31 旧均值),差值 1915.25 完全失真。

### 3. 回扣第1轮的逻辑断链(index 50)

- 本应基于第1轮 88.17 亿存款、第2轮 204.66 万净利润算 232.12% 并给整体画像。
- 结果只给出 `ratio_value=2.25 万元/亿元`(单位/口径错),既未回扣第1轮存款,也未给总结。

### 4. 排名方向描述错误

多处把"垫底/最高"误标成"第1名"(index 12、16、30),因不良率等"越低越好"指标的排名方向在多轮追问里未被正确沿用。

## 五、改进建议(按优先级)

| 优先级 | 建议 | 预期影响 |
|---|---|---|
| 🔴 最高 | **修复会话状态继承**:把上一轮 `last_metrics` / `last_date` / `last_organizations` 真正写入并传给规则与 LLM 规划阶段。目前 `session_state` 几乎恒为空。 | 直接解决 6 条报错 + 大部分日期漂移 |
| 🟠 高 | **比较期/日期解析**:追问里的"同期/上季度末/2026年一季度"应基于上一轮日期推演(上季度=上一季末、同期=去年同日),不默认退回 2024-12-31。 | 解决 index 3/15/30/50 等日期漂移 |
| 🟠 高 | **指代消解**:问题无机构/指标但属追问时,从 session 继承 `last_organizations` / `last_metrics`,避免退化全省全量。 | 解决 index 13/14/17/32/36 全量返回 |
| 🟡 中 | **阈值比较方向**:修复 index 29 这类"≥达标"被误判为"<达标",监管类判断(不良率<5、拨备≥150、资本≥10.5)方向正确。 | 解决阈值类错误 |

## 六、小结

当前多轮对话 **首轮 / 无依赖查询可靠,但跨轮继承几乎失效**:

- 50 条中仅 **13 条**实质正确(26%);
- **22 条**因上下文丢失而日期漂移(默认退回 2024-12-31)或退化全省全量返回;
- **6 条**直接报错;
- 另有阈值反向(index 29)、单位错算(index 42)等独立 bug。

**核心瓶颈在 `session_state` 没有真正传递**。优先修复上下文继承与日期推演,可一次性解决其中绝大多数错误。
